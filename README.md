# Zero-Shot, Material-Agnostic Fractional Thermography

## Project Overview
This repository accompanies the Proof of Concept (PoC) submission for the UAE Space Academy Hackathon: 813 Challenge. The project introduces a novel, physics-informed framework that maps Urban Heat Islands (UHIs) through Fractional Thermal Memory Accumulation ($I^\alpha T$), bypassing the need for traditional material classification.

## ⚠️ Intellectual Property Notice
The core computational engine of this project—the Fractional Shifted Gegenbauer Integration Matrix (FSGIM)—is currently under provisional patent review with the United States Patent and Trademark Office (USPTO). To comply with intellectual property protections and university policies, the proprietary source code for the FSGIM algorithm is withheld from this public repository. 

This repository contains a demonstration notebook that visualizes pre-computed, exported outputs (GeoTIFFs/images) generated by the pipeline, satisfying the platform's requirement for an end-to-end runnable demonstration without exposing the patented algorithmic core.

## Demonstration
The included `demo_visualization.ipynb` notebook loads and displays the pre-computed Fractional Thermal Memory Accumulation map for the Ajman urban core, demonstrating the final visual output of our analytics pipeline.
